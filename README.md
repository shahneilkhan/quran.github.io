# Quranly

Static site (index.html) + PWA + auto APK via GitHub Actions.

- APK: Releases > latest > al-quran.apk
- Signed APK: run "Create signing key (run once)", then add 3 secrets (KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS)
- Optional offline 3D stories: put three.min.js (r128) in the repo root
- Features: reading progress + streak, memorization (hifz), Qibla compass, Hijri date, offline save, privacy/credits pages
